Block Hashing Architecture

Each revision block is cryptographically sealed using SHA-256 with the following formula:

Hash = SHA256( Version || Timestamp || CanonicalJSON(Profile) || PreviousHash )

Because SHA-256 exhibits the Avalanche Effect, even modifying a single character (e.g. changing blood group from B+ to O-) completely scrambles the 256-bit digest, immediately breaking chain linkage.
